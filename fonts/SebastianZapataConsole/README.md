# Sebastian Zapata Console

Sebastian Zapata Console is a modified version of
[Cascadia Code 2407.24](https://github.com/microsoft/cascadia-code/releases/tag/v2407.24).

The font was modified by Sebastian Zapata in 2026 to reproduce the editor
typography of Visual Studio 2026 more closely on Linux.
